# Homepage content removals

## Client-requested removals

The following sections were removed from the homepage at the client's request. Their destination pages and header navigation remain available.

| Removed homepage section | Destination/content still available | SEO consideration |
| --- | --- | --- |
| Welcome to Lagnaa — “Where flavour, tradition and hospitality come together” | The original copy is retained in `src/content/home.ts` for possible later use on the Our Story page. | Removes introductory homepage copy, but the homepage still includes key location and cuisine signals in the hero and Visit section. |
| Find the right way to experience Lagnaa | Reservation, Barefoot Dining, Chilli Challenge, monthly dégustation, and cooking-class pages remain linked through navigation. | Reduces homepage internal links to these pages, but does not remove or de-index the pages. |
| Explore Indian flavours — menu preview | `/menu` remains linked from the header and hero. | Removes a homepage menu link and supporting copy, but the Menu page remains the canonical menu destination. |
| For the occasions that bring people together — private events | Contact and Events navigation links remain available. | Reduces a homepage promotion for private events, but does not remove the contact or events routes. |
| Food, atmosphere and shared moments — gallery preview | `/gallery` remains linked from the header. | Removes a homepage gallery link and image preview, but does not remove the Gallery page. |
| #RediscoverLittleIndia in Events | The page remains live at `/events/rediscover-little-india` and is now linked from the homepage Visit section as “Explore Little India”. | Removed from the Events navigation and event-card listing, but retained an internal link and the live destination page. |
| Barefoot Dining in Events navigation | `/experiences/barefoot-dining` remains linked from the homepage hero and Experiences page. | Removed from the Events dropdown because it is a core dining experience rather than an event; its destination page remains live and internally linked. |

## SEO note for future client discussions

These removals should not materially affect indexing because the underlying pages remain live and are still reachable through the main navigation. The main trade-off is less internal linking and less descriptive homepage content. If the client later asks to strengthen SEO, restore only the relevant links or short keyword-rich copy rather than reintroducing every removed visual section.
